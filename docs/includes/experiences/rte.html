CoMPAS SCT — System configuration tool

Open Source based tool and one of the software modules of the CoMPAS project related to the implementation of the IEC 61850 model

https://github.com/com-pas/compas-sct
CoMPAS - (Co)nfiguration (M)odules for (P)ower industry (A)utomation (S)ystems

Configuration tool

Responsible for generating «SCD» (Substation Configuration Description) files that present the complete details of the substation, based on the IEC 61850 standard communication data flow.

Qualification tool

Manage system versions and objects related to the «ICD» (IED Capability Description) data model.
